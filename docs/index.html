Data discoverability

Find UK public sector data and check its metadata, from your AI assistant

NDL PubSec MCP is an open-source Model Context Protocol server. It lets an AI assistant search data.gov.uk and check metadata against the UK Cross-Government Metadata Exchange Model (xGov MEM).

Every tool is read-only. No personal data is read or returned. Results come from the sources named with them, and the assistant you use may still make mistakes, so check the source before you rely on a result.

What it does

The 6 tools
ToolWhat it does
catalogue_search
Search data.gov.uk		Search the data.gov.uk catalogue of UK public sector datasets. Returns titles, publishers, licences, formats, last-modified dates and links. Read-only; no personal data is returned.
dataset_describe
Describe a dataset and check it against xGov MEM		Get one data.gov.uk dataset: its description, publisher, licence and distributions, plus a draft UK Cross-Government Metadata Exchange Model (xGov MEM) record and what that record still lacks. Nothing is guessed: fields the catalogue does not hold are reported as missing.
metadata_validate
Validate metadata against xGov MEM		Check a metadata record against the UK Cross-Government Metadata Exchange Model (xGov MEM, commit d6d9a24). Classes: ContactPoint, DataService, Dataset, Distribution, Organisation. Returns errors (must fix) and warnings (recommended), each with the attribute path.
standard_explain
Explain an open data standard		Explain open data standards used across UK government (xGov MEM, DCAT, ATRS, BODS, CSV, OpenAPI and others): purpose, status, licence and link, each with its provenance label and check date. Leave id out to list them all.
term_lookup
Look up a business term and whether it is certified		Find business terms in the configured vocabulary and report, for each, its definition, its status, who drafted it (person or AI), the review level it passed (H0 to H5) and whether that makes it certified. A term counts as certified only when it is endorsed after H2 review or above; anything unrecorded is reported as unknown, never assumed. Leave query and id out for a summary of the vocabulary.
domain_list
List the MCP servers in this estate		List the MCP servers that work alongside this one (for example the Public Sector Data Quality Commons), with what each is for, its tools, its safety statement and where its manifest came from. This server does not call them.

How well it follows xGov MEM

The validator is generated from the xGov MEM model at commit d6d9a24 (1 June 2026). It covers 5 classes. It reaches the same verdict as the model's own tests on 32 of 32 cases: 12 valid and 20 invalid examples.

Agreement with the xGov MEM test corpus, by class
ClassValid examples acceptedInvalid examples rejected
ContactPoint1 of 12 of 2
DataService5 of 59 of 9
Dataset2 of 25 of 5
Distribution4 of 44 of 4

What this does not show: the corpus is small, and some examples break more than one rule. Agreement on real catalogue records has not been measured yet. Read the conformance report.

How to use it

You need Node.js 20 or later and an MCP-capable assistant.

git clone https://github.com/cyberdudeuk/ndl-pubsec-mcp.git
cd ndl-pubsec-mcp
npm ci
npm run build

Then add node /path/to/ndl-pubsec-mcp/dist/index.js to your assistant's MCP servers. Full instructions.

Glossary

CKAN
The open-source catalogue software behind data.gov.uk. Its "action API" is what this server calls.
Class
A kind of thing in xGov MEM, for example Dataset or DataService.
CURIE
A short form of a web address, written prefix:name. For example, dcat:Dataset.
Crosswalk
A mapping from one metadata format to another; here, from a data.gov.uk entry to xGov MEM.
DAM policy
The cross-government policy on critical data assets (the successor to the Essential Shared Data Asset policy), with returns to GDS from January 2027.
data.gov.uk
The UK's national catalogue of public sector data.
DCAT
Data Catalog Vocabulary, the W3C standard for describing datasets in catalogues. xGov MEM builds on it.
Distribution
One available form of a dataset, such as a CSV file or an API.
Finding
One problem the validator reports, with a severity, a path and a message.
LinkML
The modelling language xGov MEM is written in.
MCP
Model Context Protocol: an open standard for connecting AI assistants to tools and data.
MCP server
A program that offers tools and resources to an AI assistant using MCP. This repository is one.
Provenance label
How sure a stated fact is: V verified at the primary source, S found through search, K background knowledge, U unconfirmed.
Recommended attribute
An attribute xGov MEM advises but does not require. Missing ones give warnings, not errors.
Required attribute
An attribute a record must have to meet xGov MEM.
Slot
LinkML's word for an attribute.
Tool
A single action an MCP server offers, such as metadata_validate.
Vaccination
Proving a check works by breaking the thing it guards and showing that the check fails.
xGov MEM
The UK Cross-Government Metadata Exchange Model: the endorsed model for exchanging metadata about datasets and data services across government.
